# Security and privacy

This is a collection of independent educational applications, not a shared production service. Review authentication, storage and sandboxing requirements before exposing any app to the internet.

Do not put credentials into issues, pull requests, lesson HTML, screenshots or notebook output. Use each application's environment-variable setup. Examples must contain synthetic or public information.

To report a sensitive issue, use the repository's private vulnerability-reporting channel if enabled, or contact the maintainer privately through the profile linked in the README. Do not post exploit details or leaked values publicly.

Collection checks include source scanning and link validation. These are useful checks, not a guarantee that software is free of vulnerabilities or confidential information.
