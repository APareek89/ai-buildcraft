# Slack Integration Helper

## How Slack Integration Works

Each skill can share insights, reports, and alerts to Slack channels using the Slack MCP tools.

### Setup

1. Ensure the Slack MCP server is connected in your Claude Code settings
2. Set `SLACK_ENABLED=true` in your `.env`
3. Configure channel names in `.env` (see `.env.example`)

### Usage Pattern (for all skills)

When a user asks to "share this to Slack" or "post this insight", use the Slack MCP:

```
Tool: slack_send_message
Channel: {from .env or user-specified}
Message: formatted insight/report
```

### Message Templates

#### Insight Alert
```
*{Skill Name} Insight* — {date}

{summary in 2-3 lines}

Key metrics:
• {metric 1}
• {metric 2}
• {metric 3}

_Generated by Claude Skills Toolkit_
```

#### Weekly Report
```
*Weekly {Skill Name} Report* — {date_range}

{executive summary}

{table or bullet points}

_Full report: {link or "ask Claude for details"}_
```

#### Alert (anomaly/threshold)
```
:rotating_light: *{Skill Name} Alert*

{what happened}
{severity: high/medium/low}
{recommended action}
```

### Scheduling

Users can schedule recurring Slack posts using Claude Code's `/schedule` skill:
- `/schedule "every Monday 9am" /product-analytics weekly-summary → #product-analytics`
- `/schedule "daily 6pm" /revenue daily-snapshot → #revenue-updates`
