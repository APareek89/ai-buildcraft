# Synthetic handbook example

All written passages are fictional training material. The geometric vehicle diagram is original test art generated by `scripts/make_synthetic_assets.py`. It is illustrative and does not establish the positions of real controls. Audio is generated locally as silence with measured durations, not recorded narration.

The factory verifies the asset hash allowlist, creates a new demo, then runs the normal Bundle approval and evidence validation. No customer, visitor, lead, conversation or historical usage data is included. This is the default free example for this edition.
