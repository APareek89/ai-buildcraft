# Metrics and calibration

**Question:** When positives are rare, what does good performance mean?

This folder is one lesson in the ML Hands-on Lab. Read `explainer.html` for the
conceptual lesson, then open `notebook.ipynb` and run it from top to bottom.
Every code block has a substantial Markdown explanation immediately before it.

## Run it

```bash
cd ai-buildcraft/labs/ml-foundations
source .venv/bin/activate
jupyter lab
```

Open `00-foundations-02-metrics-and-calibration/notebook.ipynb` and choose **Run All**. The notebook uses
seed 0, is CPU-only, and writes `key_figure.png` for the explainer.

## Data

The notebook uses `sklearn.datasets.make_classification` to create 4,000 seeded rows with a 6% positive class. The imbalance is intentional and the data has no external licence or download requirement.

There is no download and no local `data/` folder for this lesson.

the original curriculum record; this packaged edition has not been rerun.
