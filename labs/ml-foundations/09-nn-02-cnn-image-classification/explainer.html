CNN image classification

1. The one-sentence version

CNN image classification converts a particular structural assumption into a practical prediction or representation.

2. The intuition

Think of cnn image classification as a compact rule for deciding which observations should influence one another; the rule helps only when that notion of relatedness matches the problem.

A five-item example

A 3×3 edge filter slides across five image patches using the same nine weights. One learned edge detector can respond at the sleeve, collar, or shoe boundary.

3. The maths in plain English

\[(X*K)_{i,j}=\sum_{a,b}X_{i+a,j+b}K_{a,b}\]

K is one shared filter. At location i,j the same weights multiply a local patch; weight sharing creates translation-aware pattern detectors.

4. What the model is actually doing during training

  1. Convolve shared 3×3 filters over the image.
  2. Apply ReLU and pooling to retain strong local responses.
  3. Repeat to combine edges into motifs.
  4. Flatten pooled maps and optimize class cross-entropy.

6. Assumptions and failure modes

A CNN assumes nearby pixels and repeated local patterns matter; a fixed pixel permutation destroys that locality.

9. How it relates to its neighbours

An MLP ignores image topology. Transfer learning reuses filters learned on much larger data. Vision transformers use patch attention rather than convolution.
