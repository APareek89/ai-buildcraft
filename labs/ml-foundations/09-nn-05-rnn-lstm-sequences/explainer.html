RNNs and LSTMs for sequences

An LSTM carries a gated state while reading a sequence. Good one-step predictions from real history can still fail when the model must repeatedly feed its own predictions back as future inputs.

1. The experiment and its boundary

The notebook generates 1,400 values from two sine components with periods 40 and 9, slowly increasing amplitude, and small random noise. Each 24-value window predicts the immediately following value. This creates 1,376 input/target pairs; the final 200 windows are held out in chronological order.

The mean and standard deviation come only from fitting windows. Each model input has shape (batch, 24, 1): batch items, time positions and one scalar feature. Test windows use observed past values, including earlier observed test-period values that would be available for a rolling one-step forecast.

2. The mechanism

A vanilla RNN repeatedly combines the latest input and previous hidden state. An LSTM adds a cell state and gates that choose what to retain, write and reveal. These gates are learned functions of the current input and previous hidden state; they are not hand-coded rules about which time positions matter.

cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ gₜ
hₜ = oₜ ⊙ tanh(cₜ)
next_value = linear(last_hidden_state)

The notebook uses 20 hidden units and a linear output layer. It backpropagates mean squared error through the 24 unrolled positions. Each call starts a new window state; it does not carry hidden state between DataLoader batches. Shuffling completed training windows therefore does not shuffle the order of observations within a window.

3. Work through a tiny example

For values [1,2,3,4,5] and window length 3, the supervised pairs are [1,2,3]→4 and [2,3,4]→5. If the first forecast is 3.8, a recursive second forecast sees [2,3,3.8], whereas a one-step evaluation using observed history sees [2,3,4].

For one cell coordinate, old memory 3, forget gate .8, input gate .25 and candidate .4 give c_new=.8×3+.25×.4=2.5. The output gate then controls how much of tanh(2.5) reaches the hidden state. This separates retained memory from exposed output.

6. Baseline and what the metrics mean

The last-value baseline predicts the next value as the final observation in the input window. Both this baseline and the LSTM are scored on the same 200 chronological one-step targets using root mean squared error (RMSE), expressed on the original value scale after undoing standardization.

The training curve is standardized MSE, while the final metric is unscaled RMSE. Do not directly compare their numerical magnitudes. A stronger extension would also include a seasonal lag or lag-linear model that can exploit the known periodic structure.

8. Break the assumption

The final cell starts with the last 24 observed values, predicts one next value, appends that prediction and repeats 120 times. After the first step, some input values come from the model; after 24 steps, every input in the window does. Errors can change phase or amplitude and then compound.

The recursive comparison uses the noise-free future generating signal, whereas one-step holdout RMSE uses noisy observed targets at a different horizon and time period. Their RMSE values are not an equal-horizon benchmark or an isolated measurement of recursion. The experiment illustrates feedback of model error.
