# The bias–variance trade-off

**Question:** Why can a closer training fit make new predictions worse?

This folder is one lesson in the ML Hands-on Lab. Read `explainer.html` for the
conceptual lesson, then open `notebook.ipynb` and run it from top to bottom.
Every code block has a substantial Markdown explanation immediately before it.

## Run it

```bash
cd ai-buildcraft/labs/ml-foundations
source .venv/bin/activate
jupyter lab
```

Open `00-foundations-03-the-bias-variance-tradeoff/notebook.ipynb` and choose **Run All**. The notebook uses
seed 0, is CPU-only, and writes `key_figure.png` for the explainer.

## Data

The notebook generates a one-dimensional signal from the known function `sin(2πx) + 0.3x` and adds seeded Gaussian noise. Knowing truth permits a genuine empirical bias–variance decomposition.

There is no download and no local `data/` folder for this lesson.
