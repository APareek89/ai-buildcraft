A–Z

Accuracy
The fraction of predictions that match their labels; it can hide total failure on a rare class. See lesson →
Acquisition function
A rule such as expected improvement that uses predicted value and uncertainty to choose the next expensive experiment. See lesson →
Activation function
A nonlinear transformation such as ReLU that lets a neural network represent more than one linear map.
Anomaly score
A continuous ranking of how unusual an observation appears under a fitted notion of normality.
ARIMA
A forecast model combining autoregression, differencing, and moving-average shock terms. See lesson →
Attention
A content-dependent weighted average in which queries select information advertised by keys and carried by values. See lesson →
AUC
The probability that a randomly chosen positive receives a higher score than a randomly chosen negative. See lesson →
Backpropagation
Repeated application of the chain rule from loss back through every differentiable operation.
Bagging
Averaging models fitted to bootstrap samples to reduce prediction variance. See lesson →
Baseline
A simple, honestly evaluated rule that a more complex model must beat to justify itself. See lesson →
Bayesian optimization
Sequential optimization that uses a probabilistic surrogate and acquisition function to spend evaluations efficiently. See lesson →
Bias
Systematic error caused by assumptions too rigid to represent the useful relationship. See lesson →
BIC
A likelihood score penalized for parameter count, used here to compare Gaussian-mixture component counts. See lesson →
Calibration
Agreement between predicted probabilities and observed frequencies. See lesson →
Causal mask
A transformer mask that prevents a sequence position from attending to future positions. See lesson →
Class weight
A multiplier that makes errors on selected classes contribute more to the training loss. See lesson →
Cold start
The inability to personalize for a new user or item with no interaction history. See lesson →
Convolution
A shared local filter applied across spatial positions.
Covariance
A measure of how two centered variables move together; PCA and Gaussian mixtures use it differently. See lesson →
Credible interval
A posterior interval containing a stated probability mass under the Bayesian model.
Cross-validation
Repeated training/evaluation partitions used to estimate development performance without opening the final test. See lesson →
Curse of dimensionality
The loss of useful distance contrast as irrelevant dimensions accumulate.
Decision threshold
The score cutoff that turns a continuous probability or anomaly score into an action. See lesson →
Deviance
A likelihood-based discrepancy between observations and predictions in a generalized linear model. See lesson →
Dice score
Twice the predicted/true mask overlap divided by their combined sizes.
Diffusion model
A generator trained to reverse a gradual Gaussian noising process.
Early stopping
Ending iterative training when validation performance no longer improves.
Embedding
A vector representation whose geometry is intended to encode useful similarity. See lesson →
Epoch
One pass through the available training examples.
ETS
Exponential smoothing models that recursively update level, trend, and seasonal states. See lesson →
Explained variance
The share of total variance captured by selected principal components. See lesson →
F1 score
The harmonic mean of precision and recall at a chosen threshold. See lesson →
Gaussian process
A probability distribution over functions defined through a mean and kernel covariance. See lesson →
Generalized linear model
A linear predictor connected through a link to a target distribution's valid mean. See lesson →
Gradient
The vector of local loss slopes with respect to parameters. See lesson →
Gradient boosting
Sequential trees that fit loss gradients to correct an ensemble's current errors.
Hidden state
An internal sequence representation that carries information between time steps or latent regimes. See lesson →
Holdout set
Data isolated from fitting and tuning to provide final evidence. See lesson →
Hyperparameter
A model or training setting chosen outside ordinary parameter fitting. See lesson →
IoU
Intersection over union of predicted and true segmentation masks.
Kernel
A similarity function that implicitly supplies a richer feature space. See lesson →
KL divergence
An asymmetric measure of how one probability distribution differs from another. See lesson →
Latent factor
An unobserved compact coordinate inferred to explain variation or interactions. See lesson →
Leakage
Any route by which information unavailable at prediction time influences fitting or evaluation. See lesson →
Learning rate
The scale of each parameter update during iterative optimization.
Likelihood
The probability model assigns to observed data as a function of its parameters.
Link function
The transformation connecting a GLM's target mean to its linear predictor. See lesson →
Log-odds
The logarithm of p/(1−p), the additive scale used by logistic regression. See lesson →
LSTM
A recurrent network with gates controlling persistent memory, writing, and exposure. See lesson →
Margin
The empty band around an SVM decision boundary, determined by support vectors. See lesson →
Mode collapse
A GAN failure where many latent inputs produce only one or a few output modes.
Monotonic constraint
A rule requiring predictions to move only one direction as a selected feature increases.
OOB estimate
Performance measured for each training row using only bootstrap trees that omitted it. See lesson →
Partial dependence
Average model prediction after setting one feature to chosen values across many rows. See lesson →
Partial pooling
Group estimates borrowing strength from a learned population by amounts driven by their evidence.
Perplexity
The exponential of average next-token cross-entropy; lower means less surprise. See lesson →
Posterior
A probability distribution after conditioning a prior model on observed data.
PR-AUC
Area under the precision–recall curve, compared against positive prevalence for rare events. See lesson →
Precision
Among predicted positives, the fraction that are truly positive. See lesson →
Principal component
An orthogonal direction ordered by how much projected variance it captures. See lesson →
Q-value
Expected discounted return after taking an action in a state and following a policy thereafter.
Recall
Among true positives, the fraction the model detects. See lesson →
Regularization
A constraint or penalty that trades training fit for stability or simpler parameters. See lesson →
Residual
Observed target minus fitted prediction; remaining structure diagnoses a model. See lesson →
ROC curve
True-positive rate plotted against false-positive rate as the threshold varies. See lesson →
Seasonal naive
A forecast that copies the observation from one complete season earlier.
SHAP value
An additive attribution of a model output under a coalition and background-distribution convention. See lesson →
Silhouette score
A clustering score comparing cohesion within a cluster against separation from the nearest alternative.
SMOTE
Training-only interpolation between minority examples to create synthetic minority rows. See lesson →
Softmax
A transformation converting arbitrary scores into positive weights summing to one. See lesson →
Support vector
A training point with nonzero influence on an SVM margin. See lesson →
Train/validation/test
Separate data roles for fitting parameters, choosing settings, and making one final estimate. See lesson →
Trustworthiness
A score penalizing neighbours introduced by a low-dimensional embedding that were distant originally. See lesson →
Variance
Prediction sensitivity to which training sample happened to be observed. See lesson →
Viterbi algorithm
Dynamic programming that reconstructs the single most likely hidden-state sequence. See lesson →
