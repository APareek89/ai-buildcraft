# The ML workflow

**Question:** How can a model look almost perfect in development and still fail in use?

This folder is one lesson in the ML Hands-on Lab. Read `explainer.html` for the
conceptual lesson, then open `notebook.ipynb` and run it from top to bottom.
Every code block has a substantial Markdown explanation immediately before it.

## Run it

```bash
cd ai-buildcraft/labs/ml-foundations
source .venv/bin/activate
jupyter lab
```

Open `00-foundations-01-the-ml-workflow/notebook.ipynb` and choose **Run All**. The notebook uses
seed 0, is CPU-only, and writes `key_figure.png` for the explainer.

## Data

The notebook uses `sklearn.datasets.make_classification` to create 1,200 seeded rows with known signal, noise, and one deliberately post-outcome feature. The synthetic ground truth makes leakage unambiguous.

There is no download and no local `data/` folder for this lesson.

## Runtime budget

Planned runtime: 20 seconds. The verified clean-kernel runtime is recorded in
the original curriculum record; this packaged edition has not been rerun.
