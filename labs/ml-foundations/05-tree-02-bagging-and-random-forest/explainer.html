Bagging and random forests

1. The one-sentence version

Bagging and random forests converts a particular structural assumption into a practical prediction or representation.

2. The intuition

Think of bagging and random forests as a compact rule for deciding which observations should influence one another; the rule helps only when that notion of relatedness matches the problem.

A five-item example

Five tree probabilities [0.1,0.8,0.6,0.7,0.3] average to 0.5. Different errors cancel; five identical trees add no stability.

3. The maths in plain English

\[\hat p(x)=B^{-1}\sum_bT_b(x),\quad Var(\bar T)\approx\rho\sigma^2+(1-\rho)\sigma^2/B\]

B is tree count, σ² one-tree variance, and ρ their error correlation. More trees reduce only the uncorrelated variance.

4. What the model is actually doing during training

  1. Bootstrap training rows for every tree.
  2. Offer a random feature subset at each node.
  3. Grow diverse trees on perturbed data.
  4. Average probabilities and score each training row with trees where it was OOB.

6. Assumptions and failure modes

Averaging only helps when resampling and random feature choices make tree errors imperfectly correlated.

9. How it relates to its neighbours

Bagging randomizes rows; random forests also randomize features. Extra Trees randomizes thresholds. Boosting builds sequential rather than independent trees.
