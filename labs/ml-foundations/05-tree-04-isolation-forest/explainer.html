Isolation forest

1. The one-sentence version

Isolation forest converts a particular structural assumption into a practical prediction or representation.

2. The intuition

Think of isolation forest as a compact rule for deciding which observations should influence one another; the rule helps only when that notion of relatedness matches the problem.

A five-item example

If five points need path lengths [8,7,9,2,3] to isolate, the last two are suspicious: random cuts separate them from the main cloud in very few questions.

3. The maths in plain English

\[s(x)=2^{-E[h(x)]/c(n)}\]

h(x) is isolation path length averaged across trees; c(n) normalizes for sample size. Shorter paths make s closer to one and more anomalous.

4. What the model is actually doing during training

  1. Subsample normal training rows for each tree.
  2. Choose a random feature and split value recursively.
  3. Record path length needed to isolate each point.
  4. Average normalized path lengths and negate them into anomaly scores.

6. Assumptions and failure modes

Isolation is geometric, so a dense malicious cluster near the normal center can look perfectly ordinary.
