How one reward reaches ten tokens

The reward model scores the whole answer once. This page shows how that one number becomes a push up or down on each token, then a weight update.

Flow
Reward R (1 number)→ Critic V per token→ Surprise δ per token→ Advantage A per token→ Loss = −A · log p→ Backprop

Worked calculation: token 2 "scatters"

1. Probability p = 0.20 → log p = ln(0.20) = -1.61
2. Critic before = 5.4, after = 5.3, reward here r = 0.0
3. δ = 0.0 + 5.3 − 5.4 = -0.10
4. A = 1.00×-0.10 + 0.90×+0.50 + 0.81×+0.50 + 0.73×-0.20 + … = +1.10
5. Loss = −A × log p = −(+1.10) × (-1.61) = +1.77
6. Gradient on logit = −A×(1−p) = -0.878 → logit moves +0.439
7. New p = 0.28 ↑ more likely next time

Formulas

rt = 0 for tokens 1–9, r10 = R
δt = rt + Vt+1 − Vt  (did things look better after this token?)
At = δt + λ·δt+1 + λ²·δt+2 + …  (GAE)
Loss = −Σ At · log pt  (A is a constant, no gradient)
∂Loss/∂logitt = −At·(1 − pt)  (chosen token's logit)

Same thing in PyTorch

# logits: [10, vocab] from the policy model
# ids:    [10] tokens it actually generated
# values: [10] critic output V_t, R: float from reward model
logp = torch.log_softmax(logits, -1)
logp = logp.gather(-1, ids[:, None]).squeeze(-1)   # log p of chosen tokens

rewards = torch.zeros(10); rewards[-1] = R          # reward only at the end
next_v  = torch.cat([values[1:], torch.zeros(1)])   # V after last token = 0
delta   = rewards + next_v - values                 # surprise per token

adv, run = torch.zeros(10), 0.0
for t in reversed(range(10)):                       # GAE, back to front
    run = delta[t] + lam * run
    adv[t] = run
adv = adv.detach()                                  # reward is NOT differentiated

policy_loss = -(adv * logp).mean()                  # weighted cross-entropy
value_loss  = ((values - (adv + values).detach())**2).mean()  # train critic
(policy_loss + 0.5 * value_loss).backward()        # same backprop as SFT
optimizer.step()

Key points

  • SFT: loss = −log p(correct token). RL: loss = −A · log p(chosen token). Same backprop.
  • log p is negative, and A can be + or −. That is what sets the direction, not the raw reward.
  • Critic turns one end score into a per-token "better or worse than expected".
  • Left out here for clarity: KL penalty, PPO clipping, advantage normalisation, γ discount (set to 1).
