The fitting rule

Try every midpoint between observed weeks. For each candidate split, predict the mean on either side. Keep the split with the lowest sum of squared errors, then repeat inside each branch until the depth limit or four-point minimum leaf size stops the tree.

Try to break the story
  1. Change the shape. Which extra split does the level change need?
  2. Move the selected week across a threshold. Notice that predictions jump.
  3. Increase depth. Training error can fall while the model follows noise.
  4. Try a smaller learning rate and add more trees. Does one tree still need to solve the whole problem?
This demo measures training error only. It does not estimate future forecasting accuracy. A real time-series evaluation needs a later holdout period, time-respecting features and a baseline such as seasonal persistence.
