CNN-01

Why not just an MLP on pixels?

A 224×224 colour image is 150,528 numbers. A linear layer from that to 1,000 neurons already needs 150 million weights, and it learns "cat in top-left" separately from "cat in bottom-right".

A convolution fixes both with two ideas:

  • Local: each output looks at a small patch (e.g. 3×3), not the whole image.
  • Shared: the same small weights slide over every position.
CNN-02

A filter is a neuron that slides

Use your linear-layer picture. One filter = one neuron. Its weight vector has C_in × K × K numbers. It takes a dot product with one patch, then slides and does it again. 64 filters = 64 output channels.

out[o, i, j] = Σ_c Σ_a Σ_b w[o, c, a, b] · x[c, i+a, j+b] + bias[o] └── dot product of filter o with the patch at (i, j) ──┘
CNN-03

Shapes: kernel, stride, padding

H_out = (H + 2·P − K) / S + 1 K = kernel, S = stride, P = padding tensor layout: (B, C, H, W) vs GPT: (B, T, C)

The usual pattern: space shrinks (32 → 16 → 8) while channels grow (3 → 32 → 64 → 128). Fewer positions, richer description of each.

CNN-05

Receptive field: how far a neuron sees

Each 3×3 layer lets a neuron see 2 more pixels. Each stride-2 step doubles how fast that grows. Deep neurons see large parts of the image, so early layers find edges and later layers find shapes and objects.

rf ← rf + (K − 1) · jump jump ← jump · S (start rf = 1, jump = 1)

Compare with attention: one attention layer sees every token at once. A CNN builds a wide view slowly, layer by layer.

CNN-06

BatchNorm vs LayerNorm

Same formula, different axes. It decides which numbers share one mean and variance.

BatchNorm depends on other images in the batch, so at test time it uses running averages saved during training. That is why model.eval() matters.

CNN-07

ResNet block: the residual again

Before 2015, very deep CNNs trained worse than shallow ones. ResNet added the same trick as the transformer: add the input back.

ResNet: y = ReLU( x + F(x) ) GPT: x = x + self.sa(self.ln1(x))

CNN-09

Bridge to transformers: ViT

Vision Transformer: cut the image into 16×16 patches. Each patch becomes one token. Then run normal transformer blocks, with no causal mask. The patch cut is just a conv with kernel = stride = 16.

224 × 224 image → (224/16)² = 196 patches → (B, T=196, C=384)
