DF-01

The idea: learn to remove noise

Take a real image. Add a little noise, again and again, until it is pure static. Train a network to undo one step: given a noisy image and how noisy it is, predict the noise. To make a new image, start from pure static and remove noise step by step.

training: clean image → add noise → model guesses the noise → MSE loss sampling: pure noise → remove a bit → remove a bit → ... → image

GPT predicts the next token. A diffusion model predicts the noise. Both are just "predict a target, minimise a loss".

DF-02

The noise schedule

β_t = noise added at step t (small, 0.0001 → 0.02) α_t = 1 − β_t ᾱ_t = α_1 · α_2 · … · α_t = how much of the image is left after t steps
DF-03

Jump straight to any noise level

We do not need to add noise 500 times to get step 500. One formula jumps there directly. This makes training cheap.

x_t = √ᾱ_t · x_0 + √(1 − ᾱ_t) · ε ε ~ N(0, 1) └ signal ┘ └──── noise ────┘
DF-04

Training loop

Same shape as your notebook's loop. Each image gets a random noise level. The target is the noise we added.

loss = ‖ ε − ε_θ(x_t, t) ‖²
DF-05

The denoiser: a tiny U-Net

Input and output have the same shape (image in, noise out). A U-Net goes down (smaller, more channels), then up, with skip connections that pass fine detail across. The step t is turned into a vector with sin/cos, the same idea as positions in RoPE, and added in.

Real U-Nets stack ResBlocks (CNN-07) at each level and put attention layers at the small resolutions.

DF-06

Sampling: from noise to image

x_{t−1} = (1/√α_t) · ( x_t − β_t / √(1 − ᾱ_t) · ε_θ(x_t, t) ) + √β_t · z └──────── remove the predicted noise ────────┘ └ small fresh noise ┘

1000 steps is slow. DDIM and newer samplers skip steps and get good images in 20–50.

DF-07

Text prompts and guidance

A text encoder turns the prompt into token vectors. Inside the U-Net, cross-attention (SP-04) lets image positions ask questions (Q) of the prompt tokens (K, V). Then classifier-free guidance pushes harder toward the prompt.

ε = ε_uncond + w · (ε_cond − ε_uncond) w ≈ 5 to 8 └ no prompt ┘ └ direction the prompt adds ┘

Higher w follows the prompt more closely but looks less natural. That is the "guidance scale" slider in image tools.

DF-08

Latent diffusion (Stable Diffusion)

Diffusing full-size pixels is expensive. First compress the image with a VAE. Diffuse the small latent. Decode at the end.

image (3, 512, 512) = 786,432 numbers → VAE encoder → latent (4, 64, 64) = 16,384 numbers 48× fewer numbers. DF-03 to DF-06 run on the latent unchanged.
DF-09

Current models: DiT and flow matching

DiT: replace the U-Net with a transformer. Patchify the latent like ViT (CNN-09), run transformer blocks, unpatchify. Flow matching: draw a straight line from image to noise, and train the model to predict the direction along it.

x_t = (1 − t) · x_0 + t · ε t ∈ [0, 1] target velocity v = ε − x_0 loss = ‖ v − v_θ(x_t, t) ‖² sampling: x ← x − v_θ · Δt, from t = 1 to 0

Straight paths need fewer sampling steps. Video models use the same recipe with an extra time axis in the patches.
